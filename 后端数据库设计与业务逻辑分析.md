# 第一部分：数据库设计文档

## 一、数据库概述

### 1.1 数据库类型与配置

系统支持 **SQLite** 和 **MySQL** 两种数据库，通过环境变量 `DB_TYPE` 动态切换。

| 配置项 | SQLite | MySQL |
|--------|--------|-------|
| 数据库文件 | `backend/data/lease_contract.db` | `process.env.DB_NAME` |
| 连接方式 | 本地文件 | TCP 连接池 |
| 连接池大小 | 单连接 | 10 个连接 |
| 适用场景 | 本地开发测试 | 生产环境 |

**环境变量配置**：

```bash
# 数据库类型：sqlite | mysql
DB_TYPE=sqlite

# MySQL 配置（当 DB_TYPE=mysql 时生效）
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=your_password
DB_NAME=lease_contract

# SQLite 配置（当 DB_TYPE=sqlite 时生效）
SQLITE_PATH=./data/lease_contract.db
```

### 1.2 双数据库支持架构

系统通过统一的数据库抽象层支持双数据库，核心代码位于 `backend/src/database.ts`：

```typescript
const DB_TYPE = process.env.DB_TYPE || 'mysql';

// 统一的数据库操作接口
export const query = async <T>(sql: string, params?: any[]): Promise<T>
export const insert = async (sql: string, params?: any[]): Promise<{ insertId: number; affectedRows: number }>
export const execute = async (sql: string, params?: any[]): Promise<{ affectedRows: number }>
export const transaction = async <T>(callback: (connection: any) => Promise<T>): Promise<T>
```

### 1.3 数据库初始化流程

```
backend/src/database.ts
├── initSQLite()              # SQLite 初始化
│   ├── 创建数据库连接
│   └── 设置 WAL 模式（DELETE 模式）
├── initSQLiteSchema()        # 执行 schema 初始化
│   └── 执行 init-sqlite.sql
├── migrateMissingColumns()   # 数据库迁移
│   ├── users 表字段迁移
│   └── contracts 表字段迁移（30+ ALTER 语句）
└── initMySQL()               # MySQL 初始化
    └── 创建连接池
```

### 2.2 表关系说明

| 关系 | 父表 | 子表 | 关系类型 | 说明 |
|------|------|------|----------|------|
| 用户-合同 | users | contracts | 1:N | 一个用户可创建多个合同 |
| 合同-条款 | contracts | contract_items | 1:N | 一个合同可包含多条条款 |
| 合同-物品清单 | contracts | contract_inventory | 1:N | 一个合同可有多个物品记录 |
| 合同-签名 | contracts | signatures | 1:N | 一个合同可有多个签名记录 |
| 合同-邀请 | contracts | sign_invitations | 1:N | 一个合同可产生多个邀请 |

**注意**：预留表（contract_items、contract_inventory、signatures、sign_invitations）在代码中未被实际使用，相关数据直接存储在 contracts 表中。

## 三、表结构定义

### 3.1 users 表（用户表）

存储用户基本信息。

```sql
CREATE TABLE IF NOT EXISTS users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    openid VARCHAR(64) DEFAULT NULL,
    phone VARCHAR(20) NOT NULL UNIQUE,
    name VARCHAR(50) DEFAULT NULL,
    idcard VARCHAR(18) DEFAULT NULL,
    idcard_front VARCHAR(255) DEFAULT NULL,
    idcard_back VARCHAR(255) DEFAULT NULL,
    role VARCHAR(20) DEFAULT 'LESSEE',
    status INTEGER DEFAULT 0,
    real_name_status INTEGER DEFAULT 0,
    real_name_at DATETIME DEFAULT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

#### 字段说明

| 字段名 | 类型 | 约束 | 默认值 | 说明 |
|--------|------|------|--------|------|
| id | INTEGER | PRIMARY KEY, AUTOINCREMENT | - | 用户ID，自增主键 |
| openid | VARCHAR(64) | DEFAULT NULL | NULL | 微信 openid，用于微信登录 |
| phone | VARCHAR(20) | NOT NULL, UNIQUE | - | 手机号，登录凭证，唯一索引 |
| name | VARCHAR(50) | DEFAULT NULL | NULL | 用户姓名 |
| idcard | VARCHAR(18) | DEFAULT NULL | NULL | 身份证号 |
| idcard_front | VARCHAR(255) | DEFAULT NULL | NULL | 身份证正面照片路径 |
| idcard_back | VARCHAR(255) | DEFAULT NULL | NULL | 身份证背面照片路径 |
| role | VARCHAR(20) | DEFAULT 'LESSEE' | 'LESSEE' | 用户角色 |
| status | INTEGER | DEFAULT 0 | 0 | 账号状态（0:正常, 1:封禁） |
| real_name_status | INTEGER | DEFAULT 0 | 0 | 实名认证状态 |
| real_name_at | DATETIME | DEFAULT NULL | NULL | 实名认证时间 |
| created_at | DATETIME | DEFAULT CURRENT_TIMESTAMP | 当前时间 | 创建时间 |
| updated_at | DATETIME | DEFAULT CURRENT_TIMESTAMP | 当前时间 | 更新时间 |

#### 角色枚举值（UserRole）

| 值 | 枚举名 | 说明 |
|----|--------|------|
| LESSOR | 甲方/房东 | 可创建和管理合同 |
| LESSEE | 乙方/租客 | 签署合同 |
| ADMIN | 系统管理员 | 系统管理权限 |

#### 实名认证状态枚举（RealNameStatus）

| 值 | 枚举名 | 说明 |
|----|--------|------|
| 0 | NONE | 未认证 |
| 1 | PENDING | 认证中 |
| 2 | VERIFIED | 已认证 |
| 3 | FAILED | 认证失败 |

### 3.3 金额计算规则

**总金额计算公式**：

```
总金额 = 月租金 × 租期月数 + 押金
押金 = 月租金 × 1（固定为1个月）
```

**计算示例**（月租金 3000 元，租期 12 个月）：

```
押金 = 3000 × 1 = 3000 元
租金 = 3000 × 12 = 36000 元
总金额 = 36000 + 3000 = 39000 元
```

**代码实现**（使用整数运算避免浮点数精度问题）：

```typescript
const calculateTotalAmount = (
  monthlyRent: number,
  paymentMethod: PaymentMethod,
  months: number
): number => {
  const depositsCount = 1;  // 押金月数固定为1
  const monthlyRentFen = Math.round(monthlyRent * 100);  // 转为分
  const totalRentFen = monthlyRentFen * months;
  const depositFen = monthlyRentFen * depositsCount;
  return (totalRentFen + depositFen) / 100;  // 转为元
};
```

## 五、业务边界条件

### 5.1 输入验证规则

| 字段 | 验证规则 | 错误提示 |
|------|----------|----------|
| 身份证号 | `/^[1-9]\d{5}(18\|19\|20)\d{2}((0[1-9])\|(1[0-2]))(([0-2][1-9])\|10\|20\|30\|31)\d{3}[0-9Xx]$/` | 身份证号格式不正确 |
| 手机号 | `/^1[3-9]\d{9}$/` | 手机号格式不正确 |
| 月租金 | 大于 0 的数字，最多两位小数 | 月租金金额格式不正确 |
| 合同编号 | 格式：`LC` + 14位（年月日+6位随机） | - |
| 邀请码 | 格式：`LC` + 14位（年月日+6位随机） | - |

### 5.2 状态转换边界条件

| 当前状态 | 目标状态 | 允许条件 |
|----------|----------|----------|
| PENDING_LESSOR_SIGN (1) | PENDING_LESSEE_SIGN (2) | 甲方已签署 |
| PENDING_LESSOR_SIGN (1) | CANCELLED (5) | 甲方取消 |
| PENDING_LESSEE_SIGN (2) | SIGNED (3) | 乙方签署，邀请码未过期 |
| PENDING_LESSEE_SIGN (2) | REJECTED (4) | 乙方拒绝 |
| PENDING_LESSEE_SIGN (2) | CANCELLED (5) | 甲方或乙方取消 |
| SIGNED (3) | EXPIRED (6) | 合同到期 |
| SIGNED (3) | CANCELLED (5) | 双方同意取消 |

### 5.3 权限边界条件

| 操作 | 条件 |
|------|------|
| 查看合同详情 | created_by === userId 或 partyB_phone === userPhone 或 ADMIN |
| 修改合同 | created_by === userId 或 ADMIN，且 status === PENDING_LESSOR_SIGN |
| 删除合同 | created_by === userId 或 ADMIN，且 status === PENDING_LESSOR_SIGN |
| 甲方签署 | created_by === userId 或 ADMIN，且 status === PENDING_LESSOR_SIGN |
| 乙方签署 | partyB_phone === userPhone，且 status === PENDING_LESSEE_SIGN，邀请码未过期 |
| 取消合同 | created_by === userId 或 partyB_phone === userPhone 或 ADMIN |

### 5.4 时间边界条件

| 场景 | 边界条件 |
|------|----------|
| 邀请码有效期 | 签署后 7 天内有效 |
| 验证码有效期 | 发送后 5 分钟内有效 |
| 租赁日期校验 | lease_end 必须晚于 lease_start |
